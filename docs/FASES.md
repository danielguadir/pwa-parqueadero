# Fases del proyecto

| Fase | Objetivo | Evidencia |
|---|---|---|
| 1 | Estructura y requisitos | Plantilla navegable y esquema preliminar |
| 2 | Modelo central y API | Migraciones, operaciones reales, pruebas |
| 3 | Interfaz operativa | Entradas, salidas, tarifas, historial |
| 4 | Funcionamiento offline | IndexedDB, SW, cola y reconciliación |
| 5 | Seguridad y reportes | Autenticación, roles, caja, auditoría |
| 6 | Pruebas y despliegue | 2.000 registros, desconexiones, rendimiento |

Las fases 2-6 NO están implementadas en esta plantilla v0.1.
